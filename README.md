# Econverse

## Objetivo
Construir a interface de um marketplace moderno seguindo layout do Figma. Desenvolver com React e TypeScript. Usar boas práticas de SEO, e uso de HTML.


## Realizados
Projeto de e-commerce desenvolvido com React, TypeScript e Vite, seguindo o layout disponivel no figma.

## Tecnologias
- React
- TypeScript
- Vite
- SCSS
- Vscode
- Figma


## Funcionalidades implementadas
Vitrine de produtos consumindo dados de Json.

Carrosel de produtos relacionados.

Modal de produtos relacionados.

Interação de quantidade de produtos.

## Conclusão 
Projeto desenvolvido como parte de teste para vaga de front-end junior

```bash
npm install
npm run dev
